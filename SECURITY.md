# Security policy

## Reporting a vulnerability

GitHub private vulnerability reporting is not currently enabled for this
repository, and no other private reporting address is advertised.

Do not open a public issue, discussion, or pull request containing exploit
details, credentials, sensitive logs, or reproduction material. Withhold those
details until the repository owner provides a verified private reporting
channel. A public issue may request that private vulnerability reporting be
enabled only if it contains no sensitive technical detail.

## Scope

Reports should distinguish authorization behavior from controls this service
does not provide. Authentication, token validation or issuance, upstream claim
integrity, downstream enforcement, and audit-storage durability are outside the
service boundary unless explicitly configured and documented otherwise.

Please include affected versions, impact, and minimal reproduction steps only
through a verified private channel.
